## 🚀 Smart Features
* **Frosted Glass UI:** Implemented using `ImageFilter.blur` with high-density `sigma` values.
* **Adaptive UX:** * Dynamic mouse cursor switching for Web/Desktop.
    * Context-aware keyboards (Numeric for ID, Tel for Phone).
* **Reactive State:** Real-time form reset logic combined with a stylish data persistence preview below the fold.
* **Robust Validation:** Comprehensive null-safety checks and input verification.

## 🛠 Tech Stack
* **Framework:** Flutter (Latest Stable)
* **Language:** Dart
* **Design Pattern:** Glassmorphism / Neumorphism Hybrid
* **Architecture:** Stateful Component Design
