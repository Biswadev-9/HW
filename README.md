# 📱 Phone Number UI (Flutter)

A simple and modern Flutter UI for displaying secondary phone numbers with a clean dark theme design.

---

## 🚀 Features

* 📞 Beautiful phone number card UI
* 🎨 Clean dark theme design
* 🏷️ Labels like *Home*, *Work*
* 🕒 Sub-labels like *Added 2mo ago*, *Unverified*
* ✏️ Edit and 🗑️ Delete icons (UI only)
* 💡 Responsive and minimal layout

---

## 📸 UI Overview

* Displays a list of phone numbers
* Each card contains:

  * Phone icon
  * Phone number
  * Label (Home / Work)
  * Sub-label (status/info)
  * Edit & Delete buttons

## 📌 Code Explanation (Simple)

* `MyApp` → Main app entry
* `PhoneNumberCard` → Reusable widget for each phone number
* `Column` → Displays multiple cards vertically
* `Container` → Used for styling each card
* `Row` → Aligns icon, text, and actions horizontally
